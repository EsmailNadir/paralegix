# Files

**Files** is your firm's document store. Every document you upload lives here, organized into folders, and the same browser appears wherever documents belong to something: a matter's **Documents** tab, a client's **Files** tab, and a task's attachments all show the same file manager scoped to that record.

Open **Files** from the left sidebar for the firm-wide view.

## Browsing

The browser shows folders first, then files, with a breadcrumb trail across the top so you always know where you are. Double-click a folder to open it, or use the breadcrumb to jump back up.

Use the **search** box to find a document by name. Search covers the folder you are in and everything beneath it, and each result shows the path it was found at, so a hit three folders deep is not a mystery.

## Uploading

Click **Upload** and pick files, or drag them onto the browser. You can upload several at once, and a progress bar tracks each one. The drop zone shows exactly where the files are headed, for example "Uploads to Root / Client Documents", so you always know which folder you are about to fill before you drop anything.

Use **New Folder** to create a folder, and give it a **color** to make a frequently used folder easy to pick out.

## Previewing

Paralegix previews PDFs, common images, video, audio, text, and supported Word, Excel,
PowerPoint, and OpenDocument files without changing the stored document. HEIC and HEIF photos
from an iPhone are converted only for the on-screen preview when the browser cannot display them
natively. TIFF and other unsupported formats remain downloadable even when they cannot be
previewed.

Large PDFs load page ranges as you move through the document rather than downloading the whole
file into the page. Text files larger than 5 MB are download-only.

## Working With Files

Each row has a menu of actions:

| Action | What it does |
|---|---|
| **Preview** / **Open** | Opens a file in the in-app viewer, or opens a folder |
| **Download** | Downloads the file, or a folder as a ZIP |
| **Send for signature** | Starts a [signing request](/document-signing/overview) from this document |
| **Create share link** | Makes an expiring link for someone outside the firm (see below) |
| **Make visible to client** | Shares the file into the client portal |
| **Rename** | Renames the file or folder |
| **Move to…** | Moves it into another folder |
| **Change color** | Sets a folder's color |
| **Delete** | Removes it |

Tick several rows to act on them together: download, move, delete, share with a client, or send for signature in one go.

## Sharing With Clients

**Make visible to client** is what puts a document in the client's portal. A file inside a shared folder is shared too, so you can share a whole folder once rather than file by file. The row shows when a file is visible because of the folder it sits in rather than its own setting.

When you share, the client is notified automatically: a badge in their portal, an email, and a **New** marker on the file until they open it. Share several files in one sitting and they get a single combined email rather than one per file. A **Notify client(s)** checkbox in the sharing dialog lets you share quietly when a notification would just be noise.

See [Keeping Clients Notified](/clients/overview#keeping-clients-notified).

## Secure Share Links

A **share link** sends a file to someone who has no Paralegix account at all, such as opposing counsel or a court. When you create one you choose:

- **How long it lives**: 1 hour, 24 hours, 7 days (the default), or 30 days.
- **What it allows**: download, or view only.
- **An optional password** the recipient must enter.

The link stops working on its own when the window closes, so there is nothing to remember to revoke, though you can revoke one early at any time.

## Storage

A **Law Firm Storage** bar shows how much of your plan's storage you have used. As you approach the limit Paralegix warns you, and once you are at it new uploads are refused until you free space or upgrade. Your storage allowance is part of your [subscription](/settings/overview).

## Where Files Appear

The same documents show up in more than one place, scoped to what you are looking at:

- **Files** in the sidebar shows everything in the firm.
- A **matter's Documents tab** shows that matter's documents.
- A **client's Files tab** shows documents shared with or about that client.
- A **task's attachments** show documents attached to that task.

It is one store underneath, so a document uploaded on a matter is the same document you see in the firm-wide view, not a copy.

# Export the Docs for AI

Need to find something quickly? Instead of reading through the whole guide, you can
download the parts you care about as a single plain-text file and paste it into an
AI assistant like ChatGPT or Claude. Then ask your question in plain English and get
an answer in seconds, grounded in this documentation.

## Choose what to include

Pick the sections you want, then download them. Only need billing, matters,
and tasks? Check those three and leave the rest so the file stays short and focused.

## How to use it

1. Choose your sections above, then click **Download selected**.
2. Open your AI assistant of choice.
3. Attach the downloaded file to the chat.
4. Ask your question, for example:
   - "How do I add a time entry to a matter?"
   - "What is the difference between a flat fee and an hourly charge code?"
   - "Walk me through sending a document out for signing."

Each section is combined into one document with a heading before every page, so the
assistant knows where each part comes from.

::: tip
The content always matches the current published guide, so come back and re-download
after a while to pick up the latest documentation.
:::

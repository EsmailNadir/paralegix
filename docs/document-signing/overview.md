# Document Signing

Paralegix has a built-in document signing system. You can sign documents yourself directly in the browser, or send them to clients and other parties to sign, with full routing, security options, and a complete audit trail.

## Two Main Flows

### Sign Yourself
Upload a document and sign it directly. Your signature is applied to the PDF and a signed copy is saved.

### Send for Signing
Upload a document, place signature fields on the pages, configure who needs to sign and in what order, then send. Each signer receives an email with a secure link. Once everyone has signed, you get the completed document.

## Supported Document Formats

PDF, DOCX, DOC, ODT, RTF, and TXT. Non-PDF formats are automatically converted before signing.

## Signature Field Types

When designating fields for signers, you can place:

| Field Type | Description |
|---|---|
| **Signature** | Full drawn signature |
| **Initials** | Abbreviated drawn initials |
| **Date** | Date picker |
| **Text** | Free-form text input |
| **Checkbox** | Toggle on/off |

Each field can be marked as **required** or optional, given a label, and assigned to a specific signer role.

## Routing Modes

**Sequential**: Signers sign one at a time in order. The second signer doesn't receive their link until the first has completed.

**Parallel**: All signers receive their links at once and can sign in any order.

## Security Options

For sensitive documents you can require an **Access Code**: the signer must enter a code you set before they can view the document.

## The Signing Workspace

Open **E-Signatures** from the left sidebar. The page is split into two tabs:

- **Signing activity** lists every signing session your firm has started, with its status, which signers have completed, and a certificate to download once it is done.
- **Templates** holds the saved field layouts you reuse. See [Signing Templates](/document-signing/signing-templates).

Each tab shows a count, so you can see how much is in flight without opening it.

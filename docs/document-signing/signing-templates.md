# Signing Templates

Signing templates let you save a field layout and signer configuration so you can reuse it on future documents, which is useful for standard agreements you send regularly (retainer agreements, NDAs, consent forms, etc.).

## Saving a Template

When you have your fields placed and signers configured in the field designator, click **Save as Template** before sending. Give it a name and optionally a description.

## Using a Template

1. From the **E-Signatures** page, go to the **Templates** tab.
2. Click on a saved template.
3. Upload or select the document you want to apply it to.
4. The field layout and signer configuration load automatically.
5. Adjust anything as needed, then send.

::: tip
Signing templates store the field positions as percentages of the page size, so they adapt reasonably well to documents with the same general layout even if the page count differs.
:::

## Managing Templates

From the signing templates list you can:

- **Edit details** to rename a template or change its description.
- **Delete** a template.

There is no way to reopen a saved template's field layout on its own to edit it. To change the layout, use the template against a document as described above and adjust the fields there.
